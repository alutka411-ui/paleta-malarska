# Paleta Malarza

Prosta aplikacja internetowa do analizy zdjęcia i planowania palety kolorystycznej obrazu.

## Uruchomienie lokalne
Otwórz plik `index.html` w przeglądarce.

## Publikacja przez GitHub Pages
1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj do głównego katalogu repozytorium pliki `index.html` oraz `README.md`.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz gałąź `main` i katalog `/(root)`, a następnie kliknij **Save**.
6. Po zakończeniu publikacji GitHub pokaże adres strony w sekcji Pages.

## Informacje
- Aplikacja jest przygotowana jako pojedynczy plik HTML.
- Nie wymaga instalowania bibliotek ani budowania projektu.
- Nie ma osobnych plików CSS, JavaScript ani obrazów do wgrywania.
- Zdjęcie wybierane do analizy jest przetwarzane w przeglądarce.
- Kolory HEX farb są orientacyjnymi przybliżeniami, a nie oficjalnym wzornikiem producenta.
